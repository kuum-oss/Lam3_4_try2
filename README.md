# Лабораторна робота №3-4: Розробка GUI на C# (Avalonia UI)

Даний проект є виконанням лабораторної роботи №3-4, адаптованим для роботи на **macOS**, **Windows** та **Linux**. Проект реалізовано з використанням сучасного кросплатформенного фреймворку **Avalonia UI**, що дозволяє зберегти функціональність класичних Windows Forms у сучасному середовищі.

## 📋 Завдання лабораторної роботи

Відповідно до вимог, у проекті реалізовано:
1.  **MenuStrip (Головне меню):**
    *   `Файл` -> `Об’єкт` (виводить діалогове вікно).
    *   `Файл` -> `Вихід` (закриває програму).
    *   `Довідка` -> `Про програму` (відкриває вікно FormAbout).
2.  **MessageBox (Діалогові вікна):**
    *   Реалізовано метод `Remove` з попередженням та кнопками підтвердження (Так/Ні).
3.  **FormAbout (Вікно "Про програму"):**
    *   Власна форма з інформацією про розробника, версію та проект.
4.  **ToolStrip (Панель інструментів):**
    *   Кнопки: `Undo`, `New`, `Edit`, `Save`, `Remove`.
    *   Налаштовані іконки та підказки (ToolTipText).
5.  **ContextMenuStrip (Контекстне меню):**
    *   Викликається правою кнопкою миші, містить основні команди.
6.  **StatusStrip + Timer (Рядок стану та таймер):**
    *   Відображення поточного часу, що оновлюється кожну секунду.

## 🚀 Як запустити проект

### Попередні вимоги
Переконайтеся, що у вас встановлено [.NET SDK 8.0](https://dotnet.microsoft.com/download) або новіше.

### Запуск через термінал
1. Відкрийте термінал у кореневій папці проекту.
2. Виконайте команду:
   ```bash
   dotnet run --project Lam3_4/Lam3_4.csproj
   ```

*   **Мова програмування:** C# 12
*   **Платформа:** .NET 8.0
